# 小红书社区内容规范与违规风险指南

> 适用于：UoA Event Agent（奥克兰大学中国留学生活动推荐账号）
> 更新时间：2026年3月

---

## 一、容易被限流或封号的用词/表达

### 1.1 绝对化/夸大词（广告法违禁）

| 禁用词 | 替代建议 |
|--------|---------|
| 最好、最强、最佳、最优 | 很不错、值得一试、个人推荐 |
| 极致、极品、顶级 | 品质很高、体验感好 |
| 独一无二、万能 | 很有特色、多功能 |
| 100%、绝对、永久 | 大概率、大部分情况 |
| 性价比之王、日销冠 | 性价比不错 |

### 1.2 营销诱导词（高风险限流）

以下词汇在活动推荐笔记中需特别小心：

- **交易类**：下单、购买、价格、多少钱、代购、剁手、回购
- **利益诱导类**：白嫖、薅羊毛、免费领、活动福利、折扣、降价、优惠券
- **引流类**：微信、加我、私信、看主页、联系我、点击链接
- **互动诱导类**：求点赞、求收藏、求关注、双击、转发抽奖

**替代建议**：
- "白嫖" → "0元参加" / "不花钱体验" / "不要错过"
- "薅羊毛" → "超值体验" / "划算"
- "免费领" → "可以参加" / "开放报名"
- "活动福利" → "活动亮点" / "活动内容"
- "折扣/优惠" → "价格友好" / "学生友好"

### 1.3 引流/导流词（严重违规，可能封号）

**绝对不能出现**：
- 微信号、QQ号、手机号、邮箱地址
- 二维码图片
- 其他平台名称：淘宝、天猫、京东、拼多多、抖音
- 其他平台的水印或链接
- "加我微信"、"私聊"等明显导流话术

**活动账号合规做法**：
- 活动报名链接放在小红书官方的"笔记链接"功能中（如果支持）
- 或者引导用户"搜索活动名称"来自行找到信息
- 评论区补充信息时也要避免直接放链接

### 1.4 其他敏感领域词汇

- **政治敏感词**：避免涉及政治话题
- **玄学命理类**：算命、算卦、保佑、招财进宝、化解小人
- **医疗健康类**：治疗、减肥、美白、抗衰、消炎、杀菌、排毒
- **赌博/违法类**：赌博、代购、兼职赚钱

## 二、营销类/推广类内容的限制

### 2.1 商业推广标识

- 所有商业推广内容**必须明确标注**"广告"或"赞助"
- 即使是非付费推广，如果内容明显带有营销性质，也建议标注
- 2026年平台审核机制升级为"机器初审+人工复核"双重审核

### 2.2 对活动推荐账号的影响

作为活动信息推送账号，需要注意：

- **不要所有笔记都是推广型内容**：建议种草/推广笔记占比不超过整体的50%，穿插一些留学生活分享、校园日常等内容
- **避免被判定为营销号**：纯活动推送容易被系统识别为营销号并限流
- **保持真实人格**：以"留学生分享"的口吻写活动推荐，而非"官方通告"语气
- **禁止矩阵号操作**：不要用多个关联账号发布同质化内容

### 2.3 内容真实性要求

- 禁止虚假宣传（夸大活动效果）
- 禁止伪造身份（如冒充官方账号）
- 禁止虚构参与人数或活动效果
- 图片必须真实，不能盗用他人照片

## 三、活动推荐类笔记的注意事项

### 3.1 发布频率

- **建议**：每天 1 篇为佳，最多不超过 3 篇
- 每天发 5 篇以上会被系统判定为营销号并限流
- 发布时间建议：早上 7-9 点、中午 12-14 点、晚上 18-22 点（用户活跃时段）

### 3.2 内容结构建议

```
标题：简洁有力，包含关键词（如"奥克兰""留学生""活动"）
封面图：高质量原创图片，不带其他平台水印
正文：
  - 活动名称 + 时间 + 地点
  - 活动亮点（2-3个点）
  - 参与方式（避免直接放外部链接）
  - 个人角度的推荐理由（保持真实感）
标签：#奥克兰留学 #新西兰留学 #UoA #留学生活动 等
```

### 3.3 避免的行为

- **不要重复发布相似内容**：每篇活动笔记要有差异化，不能模板化复制
- **不要搬运内容**：从其他平台或其他账号搬运内容会被限流甚至封号
- **不要频繁修改已发布的笔记**：修改后会触发二次审核，大概率限流
- **不要在评论区大量发相同回复**：会被判定为垃圾信息
- **不要使用代购/拼单相关话术**

### 3.4 新号养号建议

- 新注册账号先养号 **7 天**
- 每天早中晚保证 10-20 分钟浏览相关内容
- 搜索"留学""奥克兰""活动"等关键词，与相关内容互动
- 养号期间不要发布任何笔记
- 完善个人资料（头像、昵称、简介），但简介中**不要放联系方式**

## 四、Emoji 使用规范

### 4.1 小红书对 emoji 没有明确的禁用规则

小红书平台目前**没有官方发布的 emoji 使用限制列表**。emoji 是小红书内容的重要排版元素，合理使用不会触发限流。

### 4.2 最佳实践

- **推荐使用**：emoji 可以提升笔记可读性，尤其是超过 300 字的长笔记，建议用 emoji 做段落分割
- **常用安全 emoji**：📍（地点）、📅（日期）、⏰（时间）、✅（确认）、🎉（庆祝）、🎯（目标）、💡（提示）等
- **避免过度使用**：一段话中 emoji 过多会显得杂乱，影响阅读体验
- **避免用 emoji 替代敏感词**：不要试图用 emoji 来绕过敏感词检测，平台能识别这种行为

### 4.3 活动笔记 emoji 排版示例

```
📍 地点：UoA Owen G Glenn Building
📅 时间：3月28日 周六 14:00-16:00
🎯 活动：留学生春季社交聚会
✅ 参与方式：现场直接参加

亮点：
🔹 认识新朋友
🔹 免费茶歇
🔹 现场小游戏
```

## 六、针对 UoA 活动账号的具体建议

### 6.1 账号定位

- 定位为"奥克兰留学生活分享"而非"活动推广平台"
- 个人简介写法示例：`在奥克兰读书的留学生 | 分享校园生活和好玩的事`
- **不要**在简介中放任何联系方式或外部链接

### 6.2 内容比例建议

| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 活动推荐 | 40-50% | 核心内容，以个人分享口吻撰写 |
| 留学生活 | 20-30% | 校园日常、美食、风景等 |
| 实用信息 | 15-20% | 选课建议、交通、生活tips |
| 互动话题 | 5-10% | 问答、投票等互动类笔记 |

### 6.3 活动笔记文案模板（安全版）

**标题写法**（避免限流）：
- "在奥克兰发现了一个超有意思的活动" ✅
- "免费！白嫖！留学生必参加的活动" ❌（"免费""白嫖"触发限流）
- "这周末去参加了XXX活动，体验分享" ✅
- "最好的留学生活动推荐" ❌（"最好"是极限词）

**正文写法**：
- 用第一人称分享口吻
- 描述活动内容而非推销活动
- 避免出现交易/价格相关词汇
- 如果活动有费用，可以写"学生价很友好"而非"打折/优惠"

### 6.4 AI 内容标识（2026年新规）

- 如果使用 AI 生成或辅助生成笔记文案，**必须在发布时勾选 AI 标识**
- 未标注 AI 内容会被限流、降低曝光
- 建议：即使使用 AI 辅助，也要大幅度人工修改，让内容更真实自然

### 6.5 发布前检查清单

- [ ] 标题中是否有敏感词或极限词？
- [ ] 正文中是否有营销/交易类词汇？
- [ ] 是否出现其他平台名称或联系方式？
- [ ] 图片是否原创且无其他平台水印？
- [ ] 是否与近期已发笔记内容重复度过高？
- [ ] 如使用 AI 辅助，是否已标注？
- [ ] 可选：使用在线违禁词检测工具（如零克查词、句无忧）二次检查
